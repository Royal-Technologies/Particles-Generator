# Particles Generator

A lightweight browser-based **Particles Generator** for creating and experimenting with animated particle backgrounds.

Built by **Royal Technologies**, this simple web tool is designed for developers and designers who want to create attractive particle-based visual effects for websites and web projects.

## Live Demo

**Try the Particles Generator:**

https://royal-technologies.github.io/Particles-Generator/

## About

**Particles Generator** is a simple frontend web application for generating particle-based visual effects directly in the browser.

Particle backgrounds are commonly used in modern websites for hero sections, landing pages, banners, dashboards, portfolios, and interactive web experiences.

This project provides a lightweight starting point for experimenting with particle effects without requiring a backend, database, or server-side application.

## Installation

Clone the repository:

```bash
git clone https://github.com/Royal-Technologies/Particles-Generator.git
```

Open the project directory:

```bash
cd Particles-Generator
```

Then open:

```text
index.html
```

in your web browser.

No server-side installation is required.
